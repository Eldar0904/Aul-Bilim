# Aul-Bilim — контент сайта на русском языке

Документ описывает русскую версию сайта Aul-Bilim, структуру публичных страниц и редактирование контента через Admin.

## Общая структура

Все страницы используют общую навигацию и footer. Русские тексты размещаются в элементах с атрибутом `lang="ru"`. Редактируемые элементы имеют ключи `data-copy` и синхронизируются с Firebase через Admin.

## Главная страница — `index.html`

Порядок блоков:

1. Hero с названием проекта, основным сообщением и фоновой фотографией.
2. Этапы проекта.
3. Основные направления: модернизация кабинетов, обучение педагогов и наставничество.
4. Статистика по регионам, школам, оснащённым классам и обученным педагогам.
5. Карта регионов и переход к школам.
6. Footer с информацией о проекте, контактами, социальными сетями и фондами.

## Программы — `programs.html`

Страница состоит из трёх направлений:

### Инновационные кабинеты

- Мебель для классов
- Лаборатории
- Цифровое оборудование

### Курсы обучения

- Предметные и методические компетенции
- Предметные знания
- Современная педагогика
- Цифровая компетентность

### Наставничество

- Наблюдение за уроками и обратная связь
- Техническая помощь
- Мастер-классы
- Систематизация воспитательной работы
- Программа для классных руководителей
- Менеджмент в образовании

Каждое направление содержит hero copy, галерею изображений и контентные блоки. В Admin можно добавлять неограниченное количество изображений в карусели, удалять их и менять порядок.

## Результаты — `results.html`

Разделы страницы:

1. Академические достижения учащихся.
2. Показатели прироста по регионам.
3. Визуальная карусель фотографий «до/после».

Статистика и изображения редактируются через раздел Results в Admin.

## О нас — `about.html`

Страница содержит миссию проекта, модель партнёрства, роли фондов и организаций, а также контактную информацию. Hero image и текстовые поля редактируются через Admin.

## Школы — `school.html`

Страница показывает регионы, районы, карточки школ, поиск и фотографии школ. Через Admin редактируются названия регионов, названия школ, описания, изображения и дополнительная медиаинформация.

## Редактирование через Admin

1. Откройте `/admin`.
2. Выберите русский язык.
3. Выберите страницу: Home, Programs, Results, About или Schools.
4. Откройте нужное направление и измените текст.
5. Нажмите кнопку сохранения.
6. Обновите публичную страницу и проверьте результат.

В Programs сначала выберите нужную вкладку: модернизация школ, курсы обучения или наставничество. Hero copy и карусель находятся внутри соответствующего направления.
